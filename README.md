# Green Dark Sign In Screen UI in Flutter 🌿✨

A clean **green dark sign in screen** built with Flutter, featuring a deep-green gradient, outlined email and password fields, a **Remember** toggle, a bright green gradient **Sign In** button and round **Facebook / Instagram / Google** buttons.

The UI is split into small, reusable components, the same way you would structure a React Native app.

## ✨ Features

- 🌲 Deep-green gradient background
- ✏️ "Sign in / Sign up" header with a tappable link
- 📝 Outlined email and password fields with floating labels
- 👁️ Eye icon to show / hide the password
- ✅ Email and password validation
- 🔘 Animated **Remember** toggle
- 💚 Green gradient **Sign In** button
- 🔵 Round social buttons for Facebook, Instagram and Google
- 🧩 Reusable components with a barrel export (like `components/index.ts`)

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Green-Dark-Sign-In-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Green-Dark-Sign-In-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
